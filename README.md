## ▫️  Características del Proyecto

* **Diseño adaptado:** Diseñado para una buena experiencia de usuario.

* **Diseño Responsive:** Adaptado para dispositivos moviles, pantallas de escritorio y tablets aun faltan pulir detalles.

* **Enfoque UX/UI:** Interfaz diseñada buscando una navegación clara, intuitiva y agradable para el usuario.
